# MCP Memory ベクトルマップ

PostgreSQL に保存された記憶の埋め込みベクトルを読み、2次元の関係図にします。静的HTMLの生成と、Androidから開ける自動更新Web表示の両方に対応します。どちらもデータベースには書き込みません。

## 静的HTMLを作る

```sh
cd /チェックアウト先/mcp-memory-public
python3 scripts/vector_graph.py --output "$HOME/vector-graph.html"
```

生成された HTML をローカルのブラウザーで開いてください。記憶を更新した場合は再実行します。現行の記憶だけに絞る場合は `--active-only`、表示件数を変える場合は `--limit 500` を指定できます。初期値は新しい順に 300 件です。

## Androidで自動更新版を見る

Androidとサーバーを同じTailscaleネットワークにつなぎます。サーバーで次を実行します。

```sh
cd /チェックアウト先/mcp-memory-public
python3 scripts/vector_graph_server.py --host "$(tailscale ip -4)" --port 8765
```

Androidのブラウザーで `http://<サーバーのTailscale IP>:8765/` を開きます。ページを開いたままで、新しい記憶や更新を約5秒ごとに取り込みます。検索・表示の切り替え・選択中の記憶は更新後もできるだけ保持します。TailscaleのIP以外やすべてのネットワークインターフェースへのバインドはプログラムが拒否します。

自動起動を設定する場合は、チェックアウト先の絶対パスを使って `scripts/run_vector_graph.sh` をユーザーのcrontabの `@reboot` に登録してください。ログは `${XDG_CACHE_HOME:-$HOME/.cache}/mcp-memory/vector-graph.log` に出ます。詳しくは [運用ガイド](operations.md) を参照してください。

この表示用サーバーは `/` と `/api/graph` を読み取り専用で公開します。Tailscaleに参加できる端末には記憶本文が見えるため、Tailnetの参加者とアクセス制御を確認してください。

同じ図の中で比較できるよう、選択された記憶の埋め込みプロバイダー・モデル・バージョン・次元がそろっていることを確認します。異なる場合はエラーを表示します。

## 図の読み方

- 点は各記憶です。色は記憶の種類を示します。中が白い点は更新前・保管済みの記憶です。
- 点の位置は保存済みベクトルの PCA による 2 次元投影です。画面上の距離は近さの目安です。
- 実線は元の次元のベクトルから計算したコサイン類似度です。スライダーで表示の下限を変更できます。各記憶につき類似度上位 3 件を候補として保持します。
- 破線はデータベースに記録された関係です。類似度だけでは事実上の関係や因果関係は分かりません。
- 記憶を選ぶと本文、記録された関係、近い記憶の値を確認できます。検索と更新前の記憶の表示切り替えもできます。

HTML には記憶本文が含まれます。プログラムは出力ファイルを所有者だけが読める権限 (`0600`) で作ります。共有する場合は含まれる情報を確認してください。
